**HM27 0.1 — первый играбельный сезон.**

- Карьера за любой из 32 клубов, сезон 2026-27: реальные составы и звенья, травмы на старте.
- Движок матча на модели NHL-STATS.RU 4.4: сила клубов по xG, ваши звенья и минуты, вратари, второй матч за два дня. Авторы голов и передач — по личному xG и пасу игроков.
- Редактор состава: 4 тройки, 3 пары, вратари, 2 звена большинства, три режима игрового времени.
- Календарь на 82 матча по формуле НХЛ, таблица (дивизионы, конференции, лига, «уайлд-кард»), статистика игроков и вратарей.
- Плей-офф до Кубка Стэнли: сетка НХЛ, серии до четырёх побед.
- Матч дня: шансы по модели, табло с ходом матча, голы, три звезды.
- 3Д-арена: площадка по размерам НХЛ, трибуны в цветах хозяев, расстановка с реальными номерами.

**Windows:** распакуйте `HM27-windows.zip`, запустите `HM27.exe`.
**macOS:** распакуйте `HM27-macos.zip`, правый клик по `HM27.app` → «Открыть». Если «повреждено» — в Терминале: `xattr -dr com.apple.quarantine путь/к/HM27.app`.

Неофициальная фанатская игра. Данные: API НХЛ, MoneyPuck.com (некоммерческое использование), DailyFaceoff.
