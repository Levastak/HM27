# HM27 — Hockey Manager 27

Менеджер НХЛ с честным движком матча. Вы — генеральный менеджер и тренер клуба: собираете звенья, выбираете вратаря, ведёте клуб через регулярку и плей-офф. Исход каждого матча считает модель прогнозов [NHL-STATS.RU](https://levastak.github.io/nhl-svodka/), проверенная на тысячах реальных матчей.

**Версия 0.3** — сезон 2026-27 в интерфейсе в духе FM24: карточки игроков с 16 характеристиками из реальной статистики (MoneyPuck, NHL EDGE), звенья как тактическая доска, экран клуба с 3Д-ареной, трансляция матча с графиком давления, травмы, стиль игры, оценки за матч.

## Как скачать и запустить

Свежая сборка — в разделе [Releases](../../releases) (релиз **dev**).

- **Windows:** скачайте `HM27-windows.zip`, распакуйте архив целиком (рядом с `HM27.exe` должна лежать папка `data_HM27_windows_x86_64`) и запустите `HM27.exe`. Если появится окно SmartScreen — «Подробнее» → «Выполнить в любом случае» (сборка не подписана сертификатом).
- **macOS (Apple Silicon и Intel):** скачайте `HM27-macos.zip`, распакуйте и перенесите `HM27.app` в «Программы». Игра не подписана сертификатом Apple, поэтому первый запуск такой:
  1. Откройте `HM27.app` двойным щелчком — macOS скажет, что не может проверить разработчика. Нажмите «Готово».
  2. «Системные настройки» → «Конфиденциальность и безопасность» → внизу «HM27 заблокировано…» → **«Всё равно открыть»** → подтвердите паролем или Touch ID.
  
  Дальше игра открывается как обычно. Способ в одну команду (Терминал): `xattr -dr com.apple.quarantine /Applications/HM27.app`

Сохранение карьеры — автоматически после каждого игрового дня. Эмблемы клубов скачиваются с сайта НХЛ при первом запуске (нужен интернет); без него — круглые значки в цветах клуба.

## Как это устроено

| Папка | Что внутри |
|---|---|
| `core/HM27.Core` | Ядро на C# без Godot: данные, состав, движок матча (уровень 1 — модель 4.4), календарь, таблица, плей-офф |
| `core/HM27.Check` | Проверка движка по критериям ТЗ 7.3: голы, овертаймы, калибровка, чувствительность к вратарю и звеньям |
| `game/` | Проект Godot 4.7 (.NET): интерфейс (`ui/`), 3Д-арена (`Match3D/`), база (`data/hm27-data.json`) |
| `data/build.py` | Сборка базы из данных NHL-STATS.RU (обновляется раз в неделю в GitHub Actions) |
| `docs/concept.md` | Концепция и ТЗ |
